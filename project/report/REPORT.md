# 2. ТЕОРЕТИЧНИЙ РОЗДІЛ

## 2.1 Моделі часових рядів: MA, AR, ARMA, ARIMA

### 2.1.1 Базові поняття

Часовий ряд — послідовність спостережень {x_t}, де t = 1, 2, …, T. Для побудови прогностичних моделей необхідна стаціонарність ряду, тобто сталість математичного сподівання, дисперсії та автокореляційної структури в часі.

**Модель ковзного середнього MA(q):**

x_t = μ + ε_t + θ₁ε_{t-1} + … + θ_q ε_{t-q}

де ε_t — білий шум, μ — константа, θ_i — параметри моделі. MA(q) описує залежність поточного значення від q попередніх шумових збурень.

**Авторегресійна модель AR(p):**

x_t = φ₁x_{t-1} + φ₂x_{t-2} + … + φ_p x_{t-p} + ε_t

AR(p) виражає поточне значення через p попередніх спостережень.

**Модель ARMA(p, q)** поєднує обидва підходи:

x_t = φ₁x_{t-1} + … + φ_p x_{t-p} + ε_t + θ₁ε_{t-1} + … + θ_q ε_{t-q}

### 2.1.2 Інтегровані моделі ARIMA

Якщо ряд є нестаціонарним (наприклад, має тренд або стохастичний блукання), застосовують оператор різниць: Δ^d x_t = (1 - L)^d x_t, де d — порядок інтегрування, L — оператор зсуву. Якщо після d-кратного диференціювання ряд стає стаціонарним, він є I(d). Модель ARIMA(p, d, q) будується на d-кратно диференційованому ряді.

**Вибір параметрів:** критерії AIC, BIC та аналіз графіків АКФ/ЧАКФ.

**Тест Дікі-Фулера (ADF):** перевіряє гіпотезу про наявність одиничного кореня (нестаціонарність). Мала p-значення (< 0.05) відхиляє гіпотезу — ряд стаціонарний.

**Оцінка якості прогнозу:**
- MSE = (1/n) Σ (y_t - ŷ_t)²
- RMSE = √MSE
- MAD = (1/n) Σ |y_t - ŷ_t|
- Theil U = RMSE(модель) / RMSE(наївний прогноз), де наївний прогноз: ŷ_t = y_{t-1}

Якщо Theil U < 1 — модель краща за наївну; якщо > 1 — гірша.

## 2.2 Показник Херста та фрактальна розмірність

### 2.2.1 Показник Херста

Показник Херста H характеризує ступінь тривалої залежності (довгої пам'яті) часового ряду:
- **H < 0.5** — антиперсистентний ряд (від'ємна автокореляція, рожевий шум);
- **H = 0.5** — відсутність залежності (білий шум, випадкове блукання);
- **H > 0.5** — персистентний ряд (позитивна автокореляція, чорний шум).

### 2.2.2 Метод R/S аналізу

Класичний метод оцінки H — аналіз перемасштабованого розмаху (R/S):

1. Ряд розбивається на сегменти довжини n.
2. Для кожного сегмента обчислюється:
   - R = max(Z) − min(Z), де Z_t = Σ_{i=1}^{t}(x_i − x̄)
   - S = стандартне відхилення сегмента
3. Усереднений R/S ≈ (an)^H.
4. Лінійна регресія log₁₀(R/S) ~ H·log₁₀(n) → H.

### 2.2.3 Фрактальна розмірність

Для часових рядів: **D = 2 − H**, де D ∈ (1, 2) — фрактальна розмірність. Чим менший H, тим більш «зубчастий» (нерегулярний) ряд і тим більша D.

## 2.3 ARFIMA та тривала пам'ять

### 2.3.1 Дробове диференціювання

Модель ARFIMA(p, d, q) допускає дробовий порядок диференціювання d ∈ (−0.5, 0.5). Оператор (1 − L)^d визначається через двіноміальний ряд:

(1 − L)^d x_t = Σ_{k=0}^{∞} δ_k x_{t-k}

де коефіцієнти δ_k рекурентно:

δ_0 = 1,   δ_k = δ_{k-1} · (k − 1 − d) / k,   k = 1, 2, …

На практиці ряд обривається при k = K (K = 50–100), оскільки δ_k → 0 достатньо швидко для |d| < 0.5.

### 2.3.2 Зв'язок з показником Херста

Для ARFIMA: **d = H − 0.5**. Якщо H = 0.5, то d = 0 — звичайна ARMA без довгої пам'яті. При H > 0.5 параметр d > 0, і ряд має тривалу пам'ять (автокореляційна функція спадає як степенева функція).

## 2.4 Мультифрактальний аналіз (MF-DFA)

### 2.4.1 Алгоритм MF-DFA (Kantelhardt et al., 2002)

1. **Профіль:** Y(i) = Σ_{t=1}^{i}(x_t − x̄), i = 1, …, N.
2. **Розбиття:** Y ділиться на 2·N_s невзаємоперекривних сегментів довжини s; для кожного сегмента v знімається полі номний тренд степеня m та обчислюється залишкова дисперсія F²(v, s).
3. **Функція флуктуацій:**
   - q ≠ 0: F(q, s) = [½·N_s · Σ_v (F²(v,s))^{q/2}]^{1/q}
   - q = 0: F(0, s) = exp{½ · (1/2N_s) · Σ_v ln[F²(v,s)]}  (границя за Лопіталем)
4. **Узагальнений показник Херста:** логарифмічна регресія F(q, s) ~ s^{h(q)}.
5. **Масовий показник:** τ(q) = q·h(q) − 1.
6. **Перетворення Лежандра:** α = dτ/dq,  f(α) = q·α − τ(q).

### 2.4.2 Інтерпретація

Якщо h(q) = const для всіх q — ряд є монофрактальним. Якщо h(q) суттєво залежить від q — мультифрактальним. Ширина мультифрактального спектра Δh = h(q_min) − h(q_max) характеризує ступінь мультифрактальності: Δh > 0.1 — виражена мультифрактальність, Δh ≤ 0.1 — близько до монофрактального.

## 2.5 Фрактальна розмірність зображень

### 2.5.1 Метод підрахунку ящиків (box-counting)

Алгоритм (за лекцією 1, с. 28–30):
1. Перетворити зображення у бінарне (пікселі переднього плану / фону).
2. Накласти сітку ящиків розміром l × l.
3. Порахувати N(l) — кількість ящиків, що містять хоча б один піксель переднього плану.
4. Повторити для l = 2, 4, 8, 16, 32, 64.
5. Лінійна регресія: log(N(l)) = D_box · log(1/l) + const.

Нахил = D_box — фрактальна розмірність. Для кривої (1D) D_box ≈ 1, для заповненої площини D_box = 2.

### 2.5.2 Вейвлет-оцінка складності (наближена)

Метод — апроксимація через розподіл енергії вейвлет-коефіцієнтів по рівнях:
1. Застосувати 2D DWT (PyWavelets) до рівня L.
2. На кожному рівні j обчислити енергію деталі: E_j = Σ(|LH_j|² + |HL_j|² + |HH_j|²).
3. Регресія: log(E_j) = β · log(2^j) + const.
4. **D_wavelet ≈ (7 − β) / 2** — евристична формула для 2D зображень.

**Важливо:** D_wavelet є наближеним показником складності масштабно-енергетичного спектру, а не точною фрактальною розмірністю. Його слід використовувати для порівняльного аналізу зображень у межах одного методу.

---

## 2.6 Фрактальний аналіз сигналів IMU

Інерційний вимірювальний блок (IMU) містить акселерометр (вісі ax, ay, az) і гіроскоп (gx, gy, gz). Для аналізу стабільності руху застосовується R/S метод:

- **H > 0.5** → персистентний, скоординований рух → платформа стабільна.
- **H ≈ 0.5** → близько до випадкового → перехідний режим.
- **H < 0.5** → антиперсистентний, хаотичний рух → нестабільність.

**Ковзне вікно:** обчислення H(t) у послідовних вікнах дозволяє виявляти моменти нестабільності в реальному часі. Поріг: H_threshold = 0.5.

## 3.1 Завдання 1: Моделювання часового ряду (ARMA/ARIMA)

### 3.1.1 Дані

Використано денні котирування валютної пари EUR/USD з сервісу yfinance за 10-річний період (2605 спостережень). Побудовано два ряди:
- **log_price** = ln(Close) — логарифм ціни закриття (нестаціонарний);
- **log_return** = Δ(log_price) = ln(P_t / P_{t-1}) — логарифмічна прибутковість (стаціонарний).

Розбиття: 2083 спостереження для навчання (80%) та 521 для тестування (20%).

| log_price | −2.778 | 0.0615 | Ні (p > 0.05) |
| log_return | −22.203 | < 0.001 | Так |

**Висновок:** log_price має одиничний корінь → ARIMA; log_return є стаціонарним → ARMA.

### 3.1.3 Модель ARMA(1,1) на log_return

**Алгоритм:** модель ARMA(1,1) побудована на логарифмічних прибутковостях (stationarity виконана). Навчання через statsmodels ARIMA з параметром order=(1,0,1).

**Оцінені параметри:**

**Тест Льюнга–Бокса на залишках:** p > 0.05 — залишки є білим шумом, модель адекватна.

### 3.1.4 Модель ARIMA(2,1,2) на log_price

**Алгоритм:** ARIMA(2,1,2) побудована на логарифмі ціни з першим різницем (d=1). Прогноз log_price перетворюється у log_return: r̂_t = p̂_t − p_{t-1}, де p_{t-1} — фактична (не прогнозована) попередня ціна.

**Оцінені параметри:** ar.L1 ≈ 4e-08, ar.L2 ≈ −1.5e-07, ma.L1 ≈ 4e-08, ma.L2 ≈ −1.5e-07. Всі АР та МА коефіцієнти практично нульові — модель вироджена у цьому наборі даних.

| Метрика | Значення |
|---|---|
| RMSE | 0.021581 |
| MAD | 0.018258 |
| Theil U | **3.481** |

Theil U = 3.481 >> 1 → ARIMA на шкалі log_return **значно гірша** за наївний прогноз.

**Пояснення:** ARIMA(2,1,2) прогнозує рівень ціни, а не прибутковість. Навіть малі похибки в прогнозі рівня ціни (накопичення різниць) призводять до великих похибок при перетворенні у шкалу прибутковості. Це не дефект реалізації, а принципова обмеженість застосування ARIMA для прогнозу прибутковостей.

### 3.3.2 Метод підрахунку ящиків

**Алгоритм:**
- Розміри ящиків: l ∈ {2, 4, 8, 16, 32, 64, 128, 256} (степені двійки).

### 3.3.3 Вейвлет-оцінка складності

**Алгоритм:** 2D DWT (PyWavelets, вейвлет Daubechies-2, до 6 рівнів). Енергія деталі на рівні j: E_j = Σ(|LH_j|² + |HL_j|² + |HH_j|²). Регресія log(E_j) ~ β · log(2^j). Складність: D_wavelet = (7 − β) / 2.

**Результати:**

|---|---|

**D_wavelet є відносним показником порівняльної текстурної складності**, а не абсолютною фрактальною розмірністю.

# 4. РЕЗУЛЬТАТИ ТА ОБГОВОРЕННЯ

## 4.1 Порівняння ARMA, ARIMA, ARFIMA

Три моделі розглядалися для прогнозування логарифмічних прибутковостей EUR/USD:

**ARMA(1,1)** досягає Theil U = 0.685, що свідчить про практичну користь моделі порівняно з наївним прогнозом. RMSE = 0.004244 є базовою лінією.

**ARIMA(2,1,2)** при прогнозуванні на шкалі log_return дає Theil U = 3.48 — майже втричі гірше за наївну модель. Це не є вадою реалізації: ARIMA проектована на прогноз рівня ціни, і перетворення прогнозів у прибутковість накопичує помилки. У своїй природній шкалі (log_price) ARIMA може бути корисною, але для задач прогнозу прибутковостей вона програє.

**ARFIMA(1, 0.061, 1)** дає найменший RMSE = 0.004152, але перевага над ARMA мінімальна. Це узгоджується з малим значенням d = 0.061: ринок EUR/USD має слабку тривалу пам'ять, і додаткова складність дробового диференціювання дає лише маргінальне покращення. На ринках із сильнішою тривалою пам'яттю (наприклад, ринки, що розвиваються, або волатильність) ARFIMA дала б виразнішу перевагу.

## 4.2 Тривала пам'ять і показник Херста

H = 0.5613 для log_return EUR/USD — незначне відхилення від H = 0.5 (ефективного ринку). Довга пам'ять є, але слабка: d = 0.06, що відповідає повільному алгебраїчному спаданню автокореляційної функції.

Мультифрактальний аналіз підтвердив монофрактальний характер ряду: Δh = 0.042 — майже константне h(q) у діапазоні q ∈ [−3, 3]. Це означає, що масштабування EUR/USD є однорідним для малих і великих флуктуацій, без значного мультифрактального ефекту. Результат узгоджується з гіпотезою відносно ефективного ринку та відомими результатами для основних валютних пар.

## 4.3 Порівняння методів box-counting та вейвлет

Методи вимірюють різні властивості зображень і не є взаємозамінними:

**Box-counting D_box:**
- Вимірює геометричну складність бінарного переднього плану.
- Дає точний результат для об'єктів із точною самоподібністю: D_box = 1.5850 для Серпінського (теоретично 1.5850).
- Чутливий до бінаризації: гауссовий шум σ ≥ 0.05 суттєво змінює D_box для простих геометричних об'єктів (контур кола: 1.28 → 1.90).

**Вейвлет D_wavelet:**
- Вимірює розподіл енергії деталі по масштабах.
- Менш чутливий до шуму (σ_noise = 0.090 vs 0.176 для D_box).
- Значення D_wavelet > 2 — наслідок евристичної формули; не слід порівнювати з D_box напряму.

Рекомендація: для точної фрактальної розмірності — box-counting; для порівняльного аналізу складності зображень під шумом — вейвлет-метод.

## 4.4 Фрактальний аналіз IMU та детектування нестабільності

Аналіз реальних даних UCI HAR (смартфон Samsung Galaxy S II, 50 Гц) підтверджує основну гіпотезу: стабільні активності (STANDING/LAYING) мають виразно вищий H, ніж динамічні (WALKING). Середнє ΔH = +0.23 по всіх 6 каналах; для акселерометрних каналів окремо ΔH ≈ +0.36 — більш чіткий сигнал.

**Ключове спостереження:** гіроскопні канали (gx, gz) зберігають H > 0.7 навіть під час ходьби, оскільки кутовий рух є ритмічним. Акселерометри чутливіші до зміни динаміки руху. Це свідчить, що для детектування нестабільності доцільно орієнтуватися саме на акселерометрні канали з нижчим порогом (H < 0.6).

Ковзне вікно не виявило вікон з H < 0.5 (0%), що є очікуваним для реальних ритмічних сигналів ходьби — на відміну від штучно антиперсистентного синтетичного сигналу. Разом із тим H(t) наочно знижується в динамічному сегменті. Фрактальний підхід залишається повністю ненаглядованим і не потребує розмітки даних.

# 5. ВИСНОВКИ

1. **Завдання 1.** Модель ARMA(1,1) є практично придатною для прогнозу log_return EUR/USD (Theil U = 0.685). ARIMA(2,1,2) на шкалі прибутковостей програє наївному прогнозу (Theil U = 3.48) — не через дефект реалізації, а через принципову невідповідність між рівневим прогнозом та шкалою прибутковостей. Тест Льюнга–Бокса підтвердив адекватність ARMA.

2. **Завдання 2.** Показник Херста H = 0.561 вказує на слабку тривалу пам'ять у EUR/USD. Параметр дробового диференціювання d = 0.061. ARFIMA дає мінімально кращий прогноз (RMSE 0.004152 vs 0.004244 у ARMA), що узгоджується з малою величиною d. MF-DFA показав Δh = 0.042 — ряд практично монофрактальний.

3. **Завдання 3.10.** Метод box-counting точно відтворив теоретичну фрактальну розмірність трикутника Серпінського (1.5850), підтвердивши коректність реалізації. Вейвлет-метод є більш стійким до гауссового шуму, але дає наближені значення D_wavelet, що не підлягають прямому порівнянню з D_box.

4. **Завдання 4.11.** Фрактальний аналіз реальних даних UCI HAR (50 Гц, 30 учасників) підтверджує розділення між стабільними (STANDING/LAYING, H ≈ 0.83) та динамічними (WALKING, H ≈ 0.59) активностями. Акселерометрні канали демонструють найчіткіший ΔH ≈ +0.37; гіроскопні канали зберігають H > 0.7 навіть при ходьбі через ритмічний характер руху. **Показник Херста є придатним ненаглядованим показником для детектування нестабільності руху — найкращих результатів досягається при аналізі акселерометрних каналів із адаптованим порогом.**
